# Вместе — распределение расходов

Локальное full-stack приложение: React, TypeScript, Tailwind CSS, Express и SQLite.

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

Интерфейс откроется на http://localhost:5173, API — на http://localhost:3001. База создаётся автоматически в `data/trips.db`.

Перед запуском замените `JWT_SECRET` в `.env` на длинную случайную строку.

## Возможности MVP

- регистрация и вход по email/паролю;
- создание поездок в RUB, EUR или USD;
- участники и предустановленные категории;
- участники без аккаунта и приглашение зарегистрированных пользователей по email;
- общие расходы с выбором плательщика и участников;
- редактирование расходов и управление составом поездки;
- дашборд по категориям и персональным балансам;
- оптимизированный список итоговых переводов.

Доли расхода делятся поровну между выбранными участниками. Владелец управляет составом поездки. Приглашённый зарегистрированный пользователь видит поездку в своём аккаунте и может добавлять, изменять и удалять собственные расходы; владелец может управлять всеми расходами.
